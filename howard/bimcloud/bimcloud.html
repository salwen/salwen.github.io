01

Large Model Visualization, manipulation, and cloud rendering

LD Cloud Render Platform is a cluster render platform which can provide render service for large 3D models. LD Cloud Render Platform is designed for various sizes of 3D models and provides powerful viewer APIs which can very easy to be adapted to different user requirements. LD Cloud Render Platform can support over 40+ 2D/3D file formats.

02

Collaborate Everywhere

LD BIMCloud provides the world’s first 3D model collaboration tool. This tool allows users to communicate in the most intuitive way. Users can add InfoNotes to the places which they are interested in and add comments. Users can very easy to add marks by a brush or texts when they on audio or video chat. LD BIMCloud is designed to improve your team work efficiency and productivity.

03

Innovation Capabilities

LD BIMCloud main features include Project Management, Model Management, The Latest Drawings, Cloud Drive, Sharing Control, Model-based Content Chat, Work Collaboration, Account/Permission Management, etc.

04

Industry-Leading Model Security

Most cloud render service use WebGL technology which needs to download 3D model to the client devices and render the 3D model from the client-side. LD BIMCloud only stores 3D model on server-side, the client-side never touch the 3D model. LD BIMCloud also offers account-based, model-based and device-based management. Which means LD BIMCloud can control models by account, model and client-side devices.
